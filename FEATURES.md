# New features (documents + attendance)

## 1. Application supporting documents
Learners apply under **Courses → Apply with documents** and must upload:
- ID / Smart ID copy (required)
- Matric certificate (required)
- Other certificates (optional)
- Doctor's note if disability is declared (required when ticked)

Files are stored in the browser (demo). Larger files are kept as name/size references.

## 2. Admin approve / decline on minimum requirements
**Approvals** shows each pending application with:
- Document checklist (ID, Matric, other, disability note)
- Badge: Meets minimum docs / Missing requirements
- Admin notes field
- **Approve (qualifies)** or **Decline (does not meet)** (reason required on decline)

Learners receive an inbox / Gmail-linked message with the decision.

## 3. Attendance register (remote)
Bottom nav **Attend**:
- **Learner:** mark present today for each approved programme from anywhere
- **Admin:** see who is present today; mark present on behalf of a learner
